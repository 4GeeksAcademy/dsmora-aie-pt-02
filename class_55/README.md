Materiales docentes:

- `resume_01.md`: guía principal de la sesión, agenda, guion y taller.
- `resume_02.md`: guía de debate y preguntas socráticas.

## Fuentes y continuidad

La clase se prepara a partir de los módulos:

- **Supervised Learning: Prediction with Labeled Data**
- **Preparing Data for Model Training**

Y continúa la clase 54 del repositorio, especialmente el proyecto WeLoveReviews y su requisito de realizar EDA, documentar limpieza, integrar un modelo preentrenado y revisar falsos negativos.

## Resultado esperado

El estudiante termina con una especificación defendible de preparación de datos, no con un modelo nuevo obligatorio. Debe poder explicar qué entra al modelo, qué se predice, cómo se divide el dataset, qué transformaciones se aplican y cómo se evita la fuga de información.

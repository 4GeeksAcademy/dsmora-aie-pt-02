# Resumen: Programming Fundamentals

Este resumen contiene los puntos principales extraídos del tutorial "Programming Fundamentals".

## Lecciones principales

- **Bienvenido a la programación:** La programación es el arte de dar instrucciones claras a las computadoras para realizar tareas.
- **Programas como instrucciones paso a paso:** Un algoritmo es una secuencia ordenada de instrucciones, como una receta.
- **Tu primer algoritmo:** Escribir instrucciones detalladas y sin ambigüedades es esencial (ejemplo: hacer un sándwich).
- **De instrucciones diarias a pseudocódigo:** El pseudocódigo permite expresar algoritmos en lenguaje sencillo y estructurado.
- **Variables:** Son "cajas" con nombre para almacenar valores, facilitando la organización de datos.
- **Tipos de datos:** Enteros, flotantes, cadenas y booleanos son los tipos básicos.
- **Operaciones básicas:** Suma, resta, multiplicación, división y asignación (=) para manipular datos.
- **Comparaciones y lógica:** Uso de operadores para crear lógica condicional y tomar decisiones en el programa.

## Conceptos clave

- La precisión y el orden en las instrucciones son fundamentales.
- El pseudocódigo ayuda a planificar la lógica antes de programar.
- Las variables y los tipos de datos permiten organizar y manipular información.
- Las operaciones y comparaciones permiten crear programas dinámicos y lógicos.

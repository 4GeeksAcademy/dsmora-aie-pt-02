# Resumen: Introduction to Programming

Este resumen contiene los puntos principales extraídos del tutorial "Introduction to Programming".

## Lecciones principales

- **Bienvenido a la programación:** Programar es dar instrucciones claras y precisas a una máquina, descomponiendo problemas en pasos simples.
- **¿Qué es la programación?:** Especificidad y claridad son esenciales, ya que las máquinas siguen instrucciones literalmente.
- **Crea tu primera instrucción:** El pseudocódigo permite escribir pasos claros y ordenados antes de programar.
- **¿Qué es el pseudocódigo?:** Escribir instrucciones paso a paso, como una receta, usando lenguaje cotidiano.
- **Diseña un plan simple:** Practica desglosar tareas en pasos claros usando START y END.
- **Variables:** Son "cajas" para almacenar información, deben tener nombres claros y descriptivos.
- **Tipos de datos:** Números, texto y valores verdadero/falso (booleanos) son los tipos básicos.
- **Operaciones básicas:** Suma, resta, multiplicación, división y asignación (=) permiten manipular datos.

## Conceptos clave

- La programación requiere instrucciones detalladas y ordenadas.
- El pseudocódigo ayuda a planificar antes de escribir código real.
- Las variables permiten almacenar y modificar información.
- Elegir el tipo de dato correcto es fundamental para el funcionamiento del programa.
- Practicar con ejemplos cotidianos (hacer un sándwich, preparar té) ayuda a entender la lógica de programación.
